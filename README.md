## About

SpeakDev is a gamified English learning platform designed specifically for Brazilian developers who want to improve their communication skills — both in everyday conversations and in technical contexts like job interviews, code reviews, and project presentations.

Inspired by Duolingo's engagement mechanics, the app combines AI-generated content, real-time speech recognition, and a personalized progress system to create an effective and enjoyable learning experience.

---

## Features

### 🎙️ Speaking Practice
- Dialogue-based conversations generated by AI (Claude Haiku via Anthropic API)
- Two tracks: **Everyday** (restaurants, travel, small talk) and **Tech** (interviews, project descriptions, code reviews)
- Real-time speech recognition using the Web Speech API
- Accuracy scoring, missed words detection, and words-per-minute tracking
- Line-by-line dialogue with Brazilian Portuguese translations

### ✍️ Writing Practice
- AI-generated Portuguese sentences for the user to translate into English
- AI-powered evaluation that accepts natural variations ("I'd like" = "I would like")
- Contextual feedback and alternative suggestions from Claude

### 📊 Dashboard & Gamification
- XP system calculated proportionally to accuracy per session
- Level progression (Newbie → Learner → Speaker → Fluent → Master)
- Daily streak with 1-day grace period (same behavior as Duolingo)
- Weekly XP chart (Recharts)
- Achievements system that unlocks based on real progress
- Configurable daily XP goal with modal selector

### 🦝 Mascot
- Custom raccoon mascot with multiple expressions (happy, sad, thinking)
- Integrated into exercise feedback and loading states

## Getting Started

### Prerequisites
- Node.js 18+
- A [Supabase](https://supabase.com) project
- An [Anthropic](https://console.anthropic.com) API key

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/speakdev.git
cd speakdev

# Install dependencies
npm install

# Copy the environment file and fill in your credentials
cp .env.example .env
```

### Environment Variables

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_APP_USER_EMAIL=your_email
VITE_APP_USER_PASSWORD=your_password
```

### Database Setup

Run the SQL schema in your Supabase SQL Editor:

```bash
# The schema file is located at:
supabase/schema.sql
```

### Edge Function Setup

```bash
# Install Supabase CLI
npm install -g supabase

# Login and link your project
supabase login
supabase link --project-ref your-project-ref

# Set the Anthropic API key as a secret
supabase secrets set ANTHROPIC_API_KEY=your-anthropic-key

# Deploy the Edge Function
supabase functions deploy generate-dialogue
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in **Google Chrome** (required for Web Speech API).

---

## Notes

- The Web Speech API works best in **Google Chrome**. Firefox and Safari have limited or no support.
- The app is designed as a single-user personal learning tool. Authentication is handled silently using fixed credentials stored in environment variables.
- AI content generation costs fractions of a cent per dialogue — estimated usage is under $1/month for daily practice.
